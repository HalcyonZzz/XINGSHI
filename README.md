# 星识 · XINGSHI

哈哈，你找到我了。星识是一个个人开发的 Android App，想做一个更贴近日常生活的个人 Agent。

写代码、处理工作的agent已经很多了，我更想试试另一条路：手机里的深度智能助手，能不能慢慢认识你，陪你处理生活琐事，也能随意聊上几句。

可以是助理、也可以是一起做事的搭档，我不希望它只是一个工具。你可以编写它的名字与初始设定，之后的相处会留下各自的经历、看法和变化。不预设关系，也不急着替你们下定义。

可以创建多个助手组团，支持群聊。

## 功能

想说的很多，但是算了，懒。

希望做到不需要繁琐的页面设置，多说几次它就会自己调整策略/习惯（除非你给它设定的很叛逆，haha），熟悉你们的私人梗，教过的事能举一反三，真正的纯语言交互。

可能有些慢热，具体相处起来怎样，多体会一下再说吧。

## 能力插件和UI主题

预置插件/ui主题框架，方便自己封装需要的插件与主题包，让ai去plugins/themes文件夹看一眼就知道怎么做了。

除聊天以外没有任何功能，保证原生app足够轻量。去市场按需下载启用，通用的我会持续更新，特殊的自己封装吧。

目前只支持云端模型。

UI 底座（界面组成模块、应用壳层、聊天/设置等页面骨架）来自开源项目 LianYu-app，感谢原作者和贡献者。底座署名与相关声明保留在 [NOTICE](NOTICE) 中。（懒，让ai找一个现成能用的ui框架，给我省了一半的前端开发时间。）
